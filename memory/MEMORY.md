# Memory Index

Check this at the start of each session. See the memory-management skill for full details.

## Structure

Two folders separate personal from project data:

- **`memory/me/`** — personal information: contacts, phone numbers, addresses, family, preferences, life events, todos. **Gitignored — never committed or pushed.**
- **`memory/project/`** — project knowledge: patterns, decisions, debugging insights. **Tracked by git — safe to commit.**

When saving a memory, pick the right folder. When in doubt, default to `me/` (safer to keep private than to accidentally publish).

## Topic Files (in `me/`)

- **people.md** — contacts, birthdays, relationships
- **preferences.md** — likes, dislikes, settings
- **facts.md** — knowledge, information, things to remember
- **todos.md** — tasks, action items, follow-ups

## Daily Logs (in `me/`)

- `daily/YYYY-MM-DD.md` — session notes, decisions, ephemeral context
