# Web Browser

Uses Claude in Chrome to control your real Chrome browser (with your logins).

Enable with `/chrome` in a Claude session. Chrome must be open.

Key tools: `mcp__chrome-devtools__navigate_page`, `mcp__chrome-devtools__click`, `mcp__chrome-devtools__fill`, `mcp__chrome-devtools__take_screenshot`, `mcp__claude-in-chrome__read_page`, `mcp__claude-in-chrome__tabs_create_mcp`.
